The application reads the data from 'players.csv', data collected from api-tennis.com and JeffSackman's Match Charting Project (https://github.com/JeffSackmann/tennis_MatchChartingProject). It asks you to input up to five tennis players you already enjoy, and searches through the data to find the closest matches to other tennis players statistically. It recommends these players to be worth watching using an LLM response. You can restrict recommendations by age, gender and ranking - it will try to recommend at least one player by nationality, and split its other recommendations into different ranking brackets (e.g. one top 10 player, one top 25 player, one top 50, one top 100). After generating responses you can view profiles for the relevant players, showing their performance across each available statistic.

Running the application requires an OpenRouter API key to be placed in a .env file in the main folder with the name OPENROUTER_API_KEY.
